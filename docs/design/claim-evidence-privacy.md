# 청구 증빙 최소수집·응답 마스킹

## 목적

가상 보험금 청구 증빙의 메타데이터에 이름, 연락처, 주소, 계좌, 진료기록 원문 같은 민감정보가 섞여 저장되거나 내부 객체 참조가 API 응답으로 노출되는 경로를 차단합니다.

## 적용 경계

- 업로드 참조는 기존과 같이 `synthetic://`만 허용합니다.
- 메타데이터 키는 `documentType`, `issuedDate`, `issuerCategory`, `pageCount`, `fixture`만 허용합니다.
- 분류값은 대문자 코드, 날짜는 ISO 날짜, 페이지 수는 1~100, 합성 표시는 boolean만 허용합니다.
- 이름·전화·이메일·주소·주민등록·계좌·상세 진단·진료기록 계열 키는 저장 전에 거절합니다.
- API 응답에서는 내부 `synthetic://` 객체 참조를 고정 마스킹하고, 과거에 직접 저장된 비허용 메타데이터도 제거합니다.

## 검증

- 민감 키와 허용되지 않은 키의 저장 전 차단
- 허용 키를 이용한 자유문자열 우회 차단
- 허용 형식의 합성 증빙 정상 저장
- 내부 참조 마스킹
- DB에 과거 민감 메타데이터가 남아 있어도 조회 응답에서 제거
- 타 사용자 청구 조회 404 경계는 기존 청구 통합 테스트로 유지

## 한계

실제 의료파일이나 실제 고객정보를 사용하지 않은 로컬 합성 검증입니다. 객체 저장소 암호화, 보존기간 만료 후 삭제, 고객·심사자·운영자 역할 분리, 접근 이력 조회는 이 변경에 포함하지 않습니다.
